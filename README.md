One line reviewing the most boring everyday object: a rubber band, written up like a failed employee in a performance review. The joke comes from how rubber bands really behave — they snap under pressure, hold nothing properly, and end up perished in the drawer with the dead pens.

## Run it

```
python3 main.py
```

Writes the single-line review to /output/entry.txt (and a byte-identical copy to entry.txt next to the script).
